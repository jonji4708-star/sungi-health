# 숭이 건강기록 — 무료 PWA

- 유료 AI 분석 및 OpenAI API 호출을 완전히 제거했습니다. API 키가 필요 없습니다.
- 검사지 이미지/PDF를 첨부하고, 검사 항목을 선택해 수치를 직접 입력한 후 저장합니다.
- 원본 혈액검사 데이터, 검사 그래프, 투약, 식단, 영상 보관, JSON 백업 기능을 포함합니다.
- 기록은 브라우저 로컬 저장소에, 영상은 IndexedDB에 저장됩니다. 클라우드 동기화는 없습니다.
- JSON 백업에는 첨부 이미지/PDF 원본이 포함되지 않으므로 원본 파일은 따로 백업하세요.

## 설치
GitHub 저장소 최상위에 이 폴더 파일들을 올린 다음 Vercel에서 Other 프레임워크, 빌드 명령 없음, 출력 디렉터리 `.`으로 배포합니다. HTTPS 주소를 Safari에서 열고 공유 → 홈 화면에 추가를 누릅니다.

## 주의
의료 검사 수치는 반드시 원본과 대조하고, 처방은 수의사에게 확인하세요. iPhone의 파일 미리보기에서는 PWA 설치/저장이 제한될 수 있습니다.


화이트 테마: 밝은 흰색 배경, 네이비 글자, 블루 버튼. AI 유료 기능 없음.
